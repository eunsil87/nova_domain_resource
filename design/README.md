기능과 데이터 규칙은 현재 [docs/SPEC.md](../docs/SPEC.md)를 우선합니다.
PNG는 화면 배치·색상·간격·스타일 참고용입니다.
Figma 프레임 경계 아래 내용은 이미지에 포함되지 않을 수 있습니다.
연간 그래프, 상세·수정 팝업, 구성안 비교 등 이 묶음에 없는 화면은 SPEC 기준으로 구현합니다.
팝업은 왼쪽 메뉴바를 제외한 콘텐츠 영역의 가로 중앙에 배치합니다.
전체 화면 내보내기는 Figma 연동 사용량 제한으로 완료하지 못했으며, 이 묶음은 확보된 주요 화면 5장입니다.

## 차기 Catalog 레이아웃 (SPEC 0.27)

- [catalog-layout-v0.27.png](catalog-layout-v0.27.png): L2 영문/하위 한글, 단일 L4 Phase, SC·L3 설계자 컨텍스트와 L4 설계·개발 단일 선택을 표현한 이미지 시안입니다.
- 예시 인력·TBD·Phase는 배치 설명용이며 초기 데이터 입력 지시가 아닙니다. 실제 코드·HTML은 아직 이 시안으로 변경하지 않았습니다.
- `SC와 동일`은 현재 담당자 ID가 같은 상태를 뜻합니다. 편집 이력에 따른 상속 예외로 해석하지 않습니다.
- 할당 현황은 진입점만 표현합니다. 그래프의 집계 기준은 미확정입니다.
